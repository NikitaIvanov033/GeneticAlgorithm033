# Evolutionary Algorithm Framework

A flexible genetic algorithm framework written in Python.

## What is this?

This is a modular framework for building genetic algorithms. You can plug in your own:
- Individual representation (binary, real, permutation, etc.)
- Fitness function
- Selection operator
- Crossover operator
- Mutation operator
- Replacement strategy

The main algorithm loop handles everything else.
